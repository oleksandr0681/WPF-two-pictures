# WPF-two-pictures

## Задание
Возмите два рисунка (или фото ), например парк летом и осенью. С помощью анимации свойства прозрачности сделайте смену картинки при загрузке постепенно .

## Описание

Учебный проект на WPF (C#), демонстрирующий плавную смену изображения с помощью анимации свойства `Opacity`.

### Функциональность

- Два изображения (`1.bmp` и `2.bmp`) размещены друг над другом в одной ячейке `Grid`.
- При загрузке окна верхняя картинка плавно становится прозрачной (`Opacity` анимируется от текущего значения до `0.0` за 10 секунд), в результате чего под ней постепенно проявляется нижняя.
- Кнопка «Первая картинка» запускает анимацию, делающую верхнее изображение прозрачным (проявляется первая картинка).
- Кнопка «Вторая картинка» запускает обратную анимацию — верхнее изображение становится непрозрачным (проявляется вторая картинка).
- Анимация реализована через `DoubleAnimation` и метод `BeginAnimation(Image.OpacityProperty, ...)`.

### Технологии

- C#
- WPF (Windows Presentation Foundation)
- XAML — разметка окна
- `System.Windows.Media.Animation` — анимация свойств

### Структура проекта

```
two_pictures/
└── two_pictures/
    ├── MainWindow.xaml       # Разметка окна: изображения и кнопки
    ├── MainWindow.xaml.cs    # Логика анимации прозрачности
    ├── App.xaml / App.xaml.cs
    ├── 1.BMP, 2.BMP           # Изображения для демонстрации
```

### Сборка и запуск

Проект собирается и запускается в Microsoft Visual Studio:

1. Открыть `two_pictures.sln` в Visual Studio.
2. Собрать проект (Build → Build Solution).
3. Запустить проект (F5).

Требуется Windows и .NET Framework (WPF-приложение).
